# 书刊9 科技管理的逻辑产业部门干部读本

> 政策研究·科技

## 关于本书

科技管理不是行政管理加科技元素，它有独立逻辑。梳理制度谱系：从学术自由传统到曼哈顿工程的有组织科研，再到当代新型举国体制的边界讨论。四章一组：制度谱系（大学、国家实验室、企业与新型研发机构的分工演化）、法治底座（科技立法、经费管理与成果转化规则）、央地关系、评估与激励（同行评议的失灵与修复）。
